\# Space Blaster



A 2D space shooter prototype developed in Unity as part of the 2D Game Design and Development coursework at Michigan State University.



\## About



Space Blaster is a pixel-art 2D space shooter focused on building a simple arcade-style gameplay loop.



The player controls a spaceship, fights enemy ships, earns points, and progresses through three playable levels.



This repository contains \*\*Version 1 (V1)\*\* of the project. V2 is currently in development, where I am continuing to iterate on the gameplay and overall player experience.



\## Features



\- Player-controlled spaceship

\- Projectile-based shooting

\- Multiple enemy types

\- Three playable levels

\- Level selection

\- Score system

\- High-score tracking

\- Main menu

\- Pixel-art visual style

\- Increasing enemy encounters across levels
